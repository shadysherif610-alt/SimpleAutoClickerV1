# SimpleAutoClickerV1

A simple and lightweight Windows auto-clicker that's easy to use.

## Features

- Adjustable clicks per second (CPS)
- Start/stop auto-clicking
- F6 hotkey to start/stop
- Simple Windows interface
- Lightweight

## Download

Download the latest version from the **Releases** section.

You can also download the ZIP included in this repository:

**SimpleAutoClickerV1.zip**

## How to Use

1. Download `SimpleAutoClickerV1.zip`.
2. Extract the ZIP to a folder.
3. Run `SimpleAutoClickerV1.exe`.
4. Set your desired CPS.
5. Press **START** to begin auto-clicking.
6. Press **START** or **F6** again to stop.

## Controls

| Control | Action |
|---|---|
| CPS | Sets clicks per second |
| START | Starts / stops the auto-clicker |
| F6 | Starts / stops the auto-clicker |

## Requirements

- Windows
- .NET 10 Desktop Runtime
